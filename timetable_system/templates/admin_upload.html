How It Works

  1. Upload your Excel or CSV file with course data.
  2. Preview the detected columns and first 5 rows.
  3. Confirm to import — new lecturers created with:

  5. Existing lecturers/courses (same surname or code+group) are skipped.
  6. After import, edit in Courses / Lecturers pages.
