How It Works

  1. Upload your Excel or CSV file with course data.
  2. New lecturers are automatically created with:
    — Username: surname (e.g. dube)
    — Password: 1234
    — Email: fdube@buse.ac.zw format
  3. New courses are created with:
    — Duration: 4 hours (default)
    — Color: Blue
    — Max students: 50 (default)
    — Level/department left blank for admin to edit
  4. Existing lecturers (same surname) and courses (same code + group) are skipped.
  5. After import, go to Courses and Lecturers to review and edit.
